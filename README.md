# 敲诗（KEYPOEM）

> 为什么做了一晚上？因为敲字写诗很解压。

“敲诗”是一个打字摸鱼进度诗生成器。它记录用户在页面书写区里的有效键盘敲击与活跃打字时长，达到用户设定的敲击目标后自动生成一句打工人小诗，并可一键生成适合分享的诗歌进度笺。

## 功能

- 页面内有效键盘敲击统计
- 连续输入时累计活跃打字时长，停止 5 秒后自动暂停计时
- 可将每句诗的敲击目标配置为 20–5000 次，默认 200 次
- 修改目标时保留当前一句的完成比例
- 实时展示下一句诗的完成进度
- 根据最近 80 个有效按键间隔计算实时 KPM（每分钟敲击数），不读取输入语义
- 按慢拍散步、从容潮汐、轻快小跑、疾速流星四档选择诗风
- 每档使用 7 组起句、转句、收句和 4 种标点节奏组合，可生成 1372 种句子，四档共 5488 种
- 组合同时参考最近的敲击间隔变化，即使平均 KPM 接近也能产生不同诗句
- 内置 32 条公版古典诗词，按速度匹配闲静、舒展、轻快、奔放四类意境，并显示作者与篇名
- 内置运行时构建的 5000 个唯一汉字总池，四档速度映射到不同语义子池
- “五千字造诗”按 `2字场景 + 2字意象 + 1字动作 + 2字落点` 生成两句七言诗，并校验入诗汉字均来自总池
- 支持古诗词库、五千字造诗、节奏原创、三路混合四种诗句来源模式
- 音乐同时使用诗词与速度：KPM 决定 BPM、音符密度和时值，诗词决定调式、主音、音色和旋律音级
- 每个入诗汉字通过 Unicode 编码映射到当前调式的音级，月夜、山水、春日、风雷、纸上五类意象对应不同音乐风格
- 同一诗词与相同速度会得到相同旋律，不同诗词在同速度下也会产生不同旋律
- 每条诗词都拥有独立的“此句成曲”按钮，只使用该句文字及其生成时的 KPM 作曲
- 底部播放器作为“今日合奏”，按顺序演奏最近最多六条诗词
- 内置代码/文档书写区，支持 Tab 缩进
- 一键生成、复制今日诗歌进度笺
- 可单独清空书写区输入，同时保留敲击数、计时、诗句和音乐
- 暂停记录与清空全部今日数据
- 可清除今天以前的全部历史记录，同时保留当前工作
- 按日期使用 `localStorage` 保存数据
- 响应式布局与减少动态效果支持

## 隐私与监听范围

这是一个纯前端 Web 原型：

- 只监听本页面书写区内的键盘事件
- 书写内容与统计数据只保存在当前浏览器的 `localStorage`
- 诗句生成只使用按键时间间隔，不分析输入内容；音乐合成也只在本地完成
- 浏览器出于安全限制，无法后台监听 VS Code、Word 等其他应用；如需系统级体验，后续可封装为 VS Code 扩展或 macOS 菜单栏应用

## 运行

项目没有第三方运行时依赖，可直接用浏览器打开 `index.html`。

推荐在项目目录启动本地静态服务器：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 统计规则

- 普通字符、回车、退格、删除和 Tab 计为有效敲击
- 输入法组合按真实键盘敲击计数，组合键与按键长按重复不计
- 最后一次有效敲击后的 5 秒内计为活跃打字时间
- 每天使用独立的数据存储键，新的一天自动从零开始
